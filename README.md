# YT AI Channel Blocker

YouTube 上で「改変または合成されたコンテンツ / Made with AI」などの公式 AI 開示ラベルが付いた動画を開いたとき、そのチャンネルをブロックリストに記録し、以降の動画一覧から該当チャンネルの動画を非表示にする Chrome 拡張機能です。

バックグラウンドでの API 通信や事前フェッチは行わず、**ユーザーが実際に開いたページの DOM だけを解析する受動的ブロック方式**を採用しています。

## 特徴

- Manifest V3 / Vanilla JS（ビルド不要）
- `/watch` ページでの AI 開示ラベル検知 → チャンネル自動記録
- ホーム・検索・関連動画など、動画カード一覧からの非表示フィルタ
- 有効/無効トグル、検知時アクション（通知のみ / 戻る / トップへ）
- 検知キーワードのカスタマイズ
- ブロックリストの個別解除、JSON エクスポート / インポート
- デバッグログ（`[YT-AI-Blocker]` プレフィックス）

## インストール手順（デベロッパーモード）

1. このリポジトリを clone または ZIP でダウンロードして解凍します。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の **デベロッパーモード** を ON にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックします。
5. このフォルダ（`manifest.json` があるディレクトリ）を選択します。
6. YouTube（`https://www.youtube.com`）を開き、拡張機能アイコンから設定を確認します。

Edge でも同様に `edge://extensions` から読み込めます。

## 使い方

1. AI 開示ラベル付きの動画ページを開くと、チャンネルがブロックリストへ追加されます。
2. ポップアップの設定に応じて、トースト通知のみ / 前のページへ戻る / トップへ戻る、のいずれかが実行されます。
3. ホームや検索結果などでは、ブロック済みチャンネルの動画カードが自動で非表示になります。
4. 誤検知した場合は、ポップアップのブロック一覧から **解除** できます。

## 設定項目

| 項目 | 説明 |
|------|------|
| 有効/無効 | 拡張機能全体の ON/OFF |
| AI検知時の動作 | `通知のみ` / `前のページへ戻る` / `YouTubeトップへ戻る` |
| 検知キーワード | 1行1キーワード。言語や文言変更に合わせて編集可能 |
| デバッグログ | DevTools コンソールへ詳細ログを出力 |

### デフォルト検知キーワード（例）

- 改変または合成されたコンテンツ
- Altered or synthetic content
- AI生成 / Made with AI
- Content was made with AI
- AIで作成されたコンテンツ
- Sounds or visuals were altered or fully generated

## 技術メモ

- YouTube の SPA 遷移には `yt-navigate-finish` と `MutationObserver`、URL ポーリングを組み合わせて対応しています。
- 動画カードは一度チェックすると `data-ai-checked="true"` を付与し、重複処理を抑えます。
- ブロックリスト更新時は `chrome.storage.onChanged` で一覧フィルタを再適用します。
- セレクタは難読化 CSS クラスではなく、`ytd-*` カスタム要素・`href`・テキスト内容を優先しています。

## 注意事項

- YouTube の DOM 構造変更により検知が一時的に効かなくなる可能性があります。その場合は検知キーワードの追加や、セレクタ更新が必要になることがあります。
- 本拡張はページ DOM の受動解析のみを行い、YouTube Data API 等へのリクエストは行いません。
- 個人利用・自己責任での利用を想定しています。
