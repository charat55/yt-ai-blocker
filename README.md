# YT AI Channel Blocker

YouTube の動画プレイヤー下に表示される**公式「AI」バッジ**を検知し、そのチャンネルをブロックリストへ記録して、以降の動画一覧から非表示にする Chrome 拡張機能です。

バックグラウンドでの API 通信は行わず、ユーザーが開いたページの DOM / ページ内データだけを解析する受動的方式です。

## 特徴

- Manifest V3 / Vanilla JS（ビルド不要）
- **公式 AI バッジのみ**を判定（説明文や「AIについて語っている動画」は対象外）
- ホーム・検索・関連動画などからの非表示フィルタ
- 有効/無効トグル、検知時アクション（通知のみ / 戻る / トップへ）
- ブロックリストの個別解除
- **「このチャンネルは許可」** で許可リストへ移動可能
- JSON エクスポート / インポート
- デバッグログ（`[YT-AI-Blocker]` プレフィックス）

## インストール手順（デベロッパーモード）

1. このリポジトリを clone または ZIP でダウンロードして解凍します。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の **デベロッパーモード** を ON にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックします。
5. このフォルダ（`manifest.json` があるディレクトリ）を選択します。
6. YouTube を開き、拡張機能アイコンから設定を確認します。

更新後は `chrome://extensions` で **再読み込み** してください。

## 使い方

1. プレイヤーと詳細の間に公式「AI」バッジがある動画を開くと、チャンネルがブロックリストへ追加されます。
2. ポップアップの設定に応じて、トースト通知のみ / 前のページへ戻る / トップへ戻る、のいずれかが実行されます。
3. ホームや検索結果などでは、ブロック済みチャンネルの動画カードが自動で非表示になります。
4. 誤ブロックした場合は、ポップアップで **このチャンネルは許可**（以降ブロックしない）または **解除** できます。

## 検知仕様

判定対象は次の公式バッジのみです。

- 表示テキスト: `AI`
- 例（日本語 aria）: `AI: コンテンツは AI を利用して作成されたものです`
- データ上: `metadataBadgeRenderer`（`label: "AI"`）

説明欄の「制作の裏側 / AI 生成」テキストや、ユーザー投稿の説明文に含まれる「AI」という言葉ではブロックしません。

プレイリスト経由の視聴（`?list=…`）でも、バッジとチャンネル情報を MAIN world のページデータから取得して検知します。

## 注意事項

- YouTube の DOM / データ構造変更により検知が一時的に効かなくなる可能性があります。
- 本拡張はページ解析のみを行い、YouTube Data API 等へのリクエストは行いません。
- 個人利用・自己責任での利用を想定しています。
